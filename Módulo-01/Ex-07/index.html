Formatação Semântica de Textos em HTML5

Nesta aula, exploramos a evolução da formatação de textos no HTML, com um foco crucial na semântica – o significado por trás da forma.

A Transição para o HTML Semântico

O HTML5 introduziu uma mudança de paradigma, valorizando o significado do conteúdo em detrimento de tags puramente de apresentação. Enquanto o HTML4 utilizava tags como <b> (negrito) e <u> (sublinhado) focadas apenas na aparência, o HTML5 oferece alternativas semânticas que enriquecem o contexto do conteúdo.

Tags Semânticas Essenciais

Vimos algumas tags importantes para formatação com significado:

  • <strong>: Indica forte importância, geralmente renderizado em negrito.
  • <em>: Enfatiza um termo, normalmente exibido em itálico.
  • <mark>: Representa um texto marcado ou destacado para referência.
  • <del>: Sinaliza texto deletado ou removido.
  • <ins>: Indica texto inserido ou adicionado.
  • <sub>: Define texto subscrito (abaixo da linha).
  • <sup>: Define texto sobrescrito (acima da linha).
  • <code>: Exibe trechos de código de computador.
  • <pre>: Mantém a formatação predefinida do texto, útil para código.
  • <q>: Representa uma citação curta.
  • <blockquote>: Indica uma citação longa ou em bloco.
  • <abbr>: Define uma abreviação ou acrônimo, com a expansão no atributo `title`.
  • <bdo>: Permite controlar a direção do texto.
  • <address>: Representa informações de contato.

Tags Obsoletas

É importante notar que algumas tags do HTML4, como <font>, <center>, <big> e <strike>, estão obsoletas ou depreciadas no HTML5, pois seu foco era puramente na apresentação. A estilização deve ser feita com CSS.

A Importância da Prática

Para internalizar o uso correto dessas tags semânticas, o Professor Gustavo Guanabara recomenda a realização dos Exercícios 007 e 008, disponíveis em https://gustavoguanabara.github.io/html-css/exercicios/. A prática é essencial para entender como aplicar cada tag de forma significativa ao seu conteúdo.

Exercício 07

Neste exercício, você irá aplicar as tags semânticas aprendidas na aula. O objetivo é criar um documento HTML que utilize essas tags de forma correta e significativa.

Siga as instruções do exercício e não hesite em consultar a documentação do HTML5 para esclarecer dúvidas sobre o uso das tags.

Lembre-se de que a semântica é fundamental para a acessibilidade e SEO (Otimização para Motores de Busca) do seu site. Usar as tags corretas ajuda os motores de busca a entenderem melhor o conteúdo da sua página.
