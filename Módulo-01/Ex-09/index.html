Trabalhando com Listas

Listas Ordenadas

Para criar uma ordered list (lista ordenada), é só utilizar a tag <ol> para delimitar a lista e <li> (list item) para identificar cada item da lista.

  1. Item 1
  2. Item 2
  3. Item 3
  4. Item 4
  5. Item 5

IMPORTANTE: segundo a W3C, a tag <ol> é de fechamento obrigatório (</ol>), já a tag <li> tem seu fechamento opcional a partir do HTML5.

A tag <ol> possui um parâmetro type, onde configuramos o tipo de marcador da lista atual. Exemplo:

  1. Item A
  2. Item B
  3. Item C
  1. Item I
  2. Item II
  3. Item III

Listas Não Ordenadas

Para criar uma unordered list (lista não ordenada), vamos usar a tag <ul> para delimitar a lista e a tag <li> para criar cada um dos seus itens internos.

  • Item 1
  • Item 2
  • Item 3
  • Item 4
  • Item 5

O marcador padrão é a bolinha preta totalmente preenchida (disc), mas existe a opção de configurar a propriedade type da tag <ul> com os valores: disc (círculo totalmente pintado), circle (borda preta, sem preenchimento) e square (quadrado preto totalmente pintado).

Misturando as Coisas

É possível criar listas mistas, configurando listas dentro de outras listas.

  1. Item 1
  2. Item 2
    1. Item 2.1
    2. Item 2.2
    3. Item 2.3
  3. Item 3
  4. Item 4
  5. Item 5

Lista de Definições

Lista de definições é como se fosse um dicionário: temos os termos e as suas descrições. É uma lista sem marcadores, mas bem útil em alguns casos. Toda lista de definições está dentro da tag <dl> (definition list). Cada termo é um <dt> (definition term) e cada descrição é um <dd> (definition description). Assim como os itens da lista, essas duas últimas tags possuem fechamento opcional, segundo a referência oficial do HTML5.
