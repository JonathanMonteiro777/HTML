Negrito / Destaque (Tags de Forma vs Tags de Sentido)

As tags semânticas possuem significado e indicam o propósito do conteúdo, enquanto as tags de forma apenas definem a aparência visual sem transmitir significado.

Tags Semânticas

As tags semânticas no HTML são aquelas que possuem um significado claro e descrevem o propósito do conteúdo que envolvem. Elas ajudam tanto os desenvolvedores quanto os navegadores e ferramentas de acessibilidade a entenderem melhor a estrutura e o significado do conteúdo de uma página.

Nesta frase tenho um termo em destaque usando a tag <strong> (semântica). A tag <strong> é usada para indicar que o texto tem um significado especial ou importância maior em relação ao restante do conteúdo.

Tags de Forma

As tags de forma são tags que não possuem significado semântico, ou seja, não informam o que o texto representa. Elas são usadas apenas para estilizar o conteúdo, como negrito ou itálico, mas não transmitem informações sobre o conteúdo em si.

Nesta frase temos um termo em negrito usando a tag <b> (de forma ou não semântica). A tag <b> é usada para aplicar negrito ao texto, mas sem adicionar significado semântico ao conteúdo.

Itálico / Ênfase

As tags semânticas no HTML são aquelas que possuem um significado claro e descrevem o propósito do conteúdo que envolvem. Elas ajudam tanto os desenvolvedores quanto os navegadores e ferramentas de acessibilidade a entenderem melhor a estrutura e o significado do conteúdo de uma página.

As tags <i> e <em>

Nesta frase, temos um termo em itálico usando a tag <i> (de forma ou não semântica). A tag <i> é usada para aplicar itálico ao texto, mas sem adicionar significado semântico ao conteúdo.

Nesta frase temos um termo em ênfase usando a tag <em> (semântica). A tag <em> é usada para indicar que o texto tem um significado especial ou importância maior em relação ao restante do conteúdo.

Texto Marcado

Podemos criar também um texto marcado com style usando a tag <mark>. A tag <mark> é usada para destacar partes do texto que são relevantes ou importantes em um contexto específico.

Texto Grande e Pequeno

Aqui temos um texto em tamanho grande utilizando a tag <big> e um texto em tamanho pequeno utilizando a tag <small> neste parágrafo.

Texto Pequeno

A tag <small> é usada para indicar texto que deve ser exibido em um tamanho menor em relação ao texto ao redor.

Texto Deletado

Podemos marcar um texto como excluído para indicar que ele foi removido ou que não deve ser considerado como parte do conteúdo principal.

Texto Inserido

A tag <ins> é usada para indicar um texto inserido, destacando que ele foi adicionado ao conteúdo original.

Existe também o sublinhado com a tag <u> (não semântica). A tag <u> é usada para aplicar um sublinhado ao texto, mas não transmite significado semântico.

Texto Sobrescrito

A tag <sup> é usada para criar texto sobrescrito, como em expressões matemáticas ou científicas, onde é necessário exibir expoentes ou outras notações elevadas. Por exemplo, podemos representar uma equação como x20 + 3.

Texto Subscrito

Para representar elementos como H2O, usamos a tag <sub>, que é utilizada para criar texto subscrito.
