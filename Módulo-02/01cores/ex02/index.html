Resumo: O Poder das Cores

Dev-Web - Prof. Gustavo Guanabara

Circulo Cromático

A Emoção das Cores

  • As cores influenciam as emoções e decisões dos usuários em websites.
  • Afeta o tempo de permanência e decisões de compra.
  • Neil Patel: 90% da decisão sobre um produto é baseada na cor nos primeiros 90 segundos.
  • Diferentes cores evocam diferentes emoções (ex: azul - confiança, vermelho - energia).
  • Considerar associações culturais e de mercado ao escolher cores.

O Círculo Cromático

  • Base para entender a harmonia das cores.
  • Cores Primárias: Amarelo, Vermelho e Azul.
  • Cores Secundárias: Laranja (amarelo + vermelho), Violeta/Roxo (azul + vermelho), Verde (azul + amarelo).
  • Cores Terciárias: Mistura de uma primária com uma secundária (ex: amarelo-esverdeado).

Temperatura e Harmonia das Cores

Temperatura das Cores

  • Cores Quentes: Vermelho, laranja e amarelo (calor, proximidade).
  • Cores Frias: Azul, verde e roxo (calma, frescor).

Esquemas Harmônicos

  • Cores Complementares: Opostas no círculo (alto contraste).
  • Cores Análogas: Viznhas no círculo (baixo contraste, harmonia).
  • Cores Análogas + 1 Complementar: Combinação dos anteriores.
  • Cores Análogas Relacionadas: Duas análogas, pula uma, escolhe a seguinte.
  • Cores Intercaladas: Cores com intervalos constantes.
  • Cores Triádicas: Três cores equidistantes (alto contraste).
  • Cores em Quadrado: Quatro cores com contraste razoável.
  • Cores Tetrádicas: Dois pares de cores complementares.
  • Monocromia: Variações de saturação e brilho de uma cor (degradê).

Aplicação Prática em CSS

  • Ferramentas online (ex: Adobe Color) auxiliam na escolha de paletas.
  • Cores em CSS podem ser definidas por:
    • Nomes textuais (limitado).
    • Códigos hexadecimais (#RRGGBB).
    • Funções rgb(), rgba(), hsl(), hsla().
  • O VSCode oferece auxílio visual para seleção de cores.

Representação de Cores

  • RGB: rgb(vermelho, verde, azul) - valores de 0 a 255.
  • Hexadecimal: #RRGGBB - representação hexadecimal do RGB.
  • HSL: hsl(matiz, saturação%, luminosidade%).
  • RGBA: rgba(vermelho, verde, azul, alfa) - alfa para transparência (0 a 1).
  • HSLA: hsla(matiz, saturação%, luminosidade%, alfa) - alfa para transparência (0 a 1).

Gradientes em CSS

  • Utiliza a propriedade background-image.
  • Funções:
    • linear-gradient(ângulo, cor1 posição, cor2 posição, ...)
    • radial-gradient(forma tamanho at posição, cor1 posição, cor2 posição, ...)
  • Permite criar transições suaves entre cores.

Descobrindo Códigos de Cores

  • Extensão Colorzilla para Google Chrome.
  • Permite identificar o código de cores de qualquer elemento em uma página web.

Conclusão

A escolha de cores é crucial no design web, afetando a experiência do usuário e a percepção do conteúdo. Compreender a psicologia das cores e a harmonia cromática, juntamente com as ferramentas CSS, é essencial para criar websites eficazes e visualmente agradáveis. A prática e a exploração são incentivadas.
